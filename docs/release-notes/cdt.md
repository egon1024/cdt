# cdt bundle release notes

Sparse, bundle-level notes for the meta `cdt` utility and cross-cutting release
changes. Per-utility changelogs live in sibling files (see
[README.md](README.md)).

## 0.7.0

### Changed

- Bundle releases continue to ship `cdt` and bundled utilities from a single
  manifest; use `cdt version` to print bundle and component versions together.
